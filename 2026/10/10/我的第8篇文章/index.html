今天是 2026 年 10 月 10 日，我把博客重新搭了起来。

起因

之前的博客源码文件夹被我误删了，线上的网站虽然还在，但没法再写新文章。好在 GitHub 上保留着生成后的网页，我花了一个晚上，从头把环境搭了一遍：

  • 安装 Node.js
  • 安装 Hexo 和 Butterfly 主题
  • 修复了几个小问题

踩过的坑

  1. 权限问题：全局安装时遇到 EACCES，原因是 npm 缓存目录里有 root 权限的文件。
  2. 主题名拼错：把 butterfly 写成了 lbutterfly，结果页面一片空白，只提示 No layout。
  3. 端口被占用：旧的 hexo s 进程没有关，导致 4000 端口无法使用。

这些问题看起来都很小，但排查起来很花时间。遇到报错时，先认真读一遍提示信息，往往答案就写在里面。

接下来的计划

  • 把源码备份到 GitHub 的 hexo 分支
  • 把旧文章整理成 Markdown 迁移过来
  • 调整主题的头像、菜单和背景图
  • 坚持写作，每周至少更新一篇

写在最后

这次误删让我明白一件事：重要的东西一定要有备份。从今天起，我的博客源码会同时放在本地和 GitHub 上，再也不怕丢了。

希望这个博客能陪我走得更远。
