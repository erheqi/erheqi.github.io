重点：把源码备份到 GitHub

线上的 master 分支只有生成后的网页。源码要推到另一个分支，比如 hexo：

这样仓库里就有两个分支，各司其职：

  • master：线上网站（hexo d 自动更新）
  • hexo：博客源码（手动提交）

主题用 npm 安装，node_modules 默认被 .gitignore 忽略，不会冲突。如果以后改用 git clone 的方式放主题，要先删掉主题目录里的 .git。

小结

生成的网页不是源码，源码一定要有备份。
