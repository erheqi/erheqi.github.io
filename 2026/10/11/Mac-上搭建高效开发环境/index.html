每次换电脑或者重装系统，我都会重新整理一遍开发环境。为了不再重复踩坑，这里记一份相对稳定的最小配置清单。

1. 先安装系统基础工具

在 Mac 上，最推荐的第一步不是装 IDE，而是把命令行基础环境补齐。最关键的是：

  • 安装 Xcode Command Line Tools
  • 安装 Homebrew
  • 安装 Git
  • 安装 Node.js / nvm
  • 安装 zsh 并配置 alias

如果是第一次使用 Mac，很多人会忽略命令行工具。实际上，很多后续问题都是因为环境不完整而引发的。果断提前装好，后面省心很多。

3. 版本管理器比直接装全局更稳

Node.js 这类工具最容易踩坑。最省心的方法是用 nvm 管理版本：

这样当某个项目需要旧版本 Node 时，可以切换版本，而不会破坏当前开发环境。

4. IDE 和编辑器选择

如果你是写前端或轻量脚本，VS Code 可以说是最省力的选择。推荐至少安装下面这些插件：

  • GitHub Copilot
  • ESLint
  • Prettier
  • Markdown All in One
  • Auto Rename Tag
  • GitLens

这些插件并不一定都必须装，但真正使用一段时间后，你会发现它们提高效率非常明显。

5. 统一自己的工作流

最后最重要的是建立固定的工作流，不要每次都“临时抱佛脚”。比如：

  • 新项目统一用 Git 初始化
  • 代码统一通过分支管理
  • 文章统一用 Markdown
  • 关键文件统一做备份

开发环境本身并不复杂，真正值得花时间的是“形成稳定的使用习惯”。一旦你养成固定流程，后面所有事情都会顺很多。

这篇文章本身也算是一份提醒：不是把工具装满，而是让工具适合你自己。
